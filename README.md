# schedule

Расписание занятий «Интерактивная школа МУДРО» — PWA-приложение (работает офлайн, устанавливается на телефон и компьютер).

## Публикация

Достаточно загрузить файлы в репозиторий — GitHub Pages отдаёт приложение по HTTPS.

## Обновление приложения

При любом изменении `index.html`, `app.js`, `app.css` или `core.js` увеличьте версию кэша в начале `sw.js`:

```js
const CACHE_VERSION = 'mudro-v1'; // → 'mudro-v2'
```

Иначе у пользователей продолжит работать старая версия из кэша. Новая версия применится автоматически: страница перезагрузится один раз и покажет уведомление «Приложение обновлено!».

## Установка

- **Android/Chrome:** кнопка «Установить» в приложении или меню браузера → «Установить приложение».
- **iOS/Safari:** Поделиться → «На экран “Домой”».
- **Компьютер:** значок установки в адресной строке Chrome/Edge.
